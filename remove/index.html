How to use

A card for each of 133 people-search sites and data brokers, for getting your personal information removed and checking later that it stayed gone.

  1. California residents: start with DROP (first ★ card). One request goes to every registered data broker in the state, and they have to keep honoring it.
  2. Create a dedicated email address just for removals, so confirmations don't tie back to your main inbox. Put it under Menu → My details.
  3. Do the ★ Priority sites first; they feed many smaller sites. Then wait about a week before working the rest, since some listings disappear on their own.
  4. On each site, search for yourself first. Many forms want the exact web address of your listing. If you're not listed, set the status to Not listed.
  5. Tap Site to open the removal page and submit the request, then tap Status. Requested — waiting fills in today as the requested date. Use Email for sites that only take email requests.
  6. If a site demands photo ID, never submit a fake one. Cover everything except your name and photo, or send the email request instead and mark it Refused / stuck if they won't budge.
  7. Mark Removed — verified only after you've searched again and the listing is gone; that fills in today as the verified date. The card comes back as Recheck due after the number of days set in the Menu (90 by default), because listings often return.
  8. Missing a site? Tap + to add it.
  9. Save to file with a passphrase now and then. The record shows exactly where your information lives, so protect it like the information itself.

Getting around

  • Drag the cards up or down, use ▲ ▼, the arrow keys or the mouse wheel. Tap a letter to jump.
  • The buttons under the search box show only the sites you need: ★ Priority, Not started, In progress, Done, Recheck due or Email-only.
  • List shows every site at once. On a wide screen the list and the selected card sit side by side.

Install REMOVE

REMOVE is installed. Open it from your home screen or apps list; it works without a signal.

Install REMOVE as an app on this device. It opens in its own window and works offline.

  1. Open this page in Safari
  2. Tap the Share button
  3. Tap Add to Home Screen, then Add
  4. Open REMOVE from the Home Screen and track your progress there. Progress saved in a Safari tab stays in Safari.
  1. In Safari's menu bar, choose File → Add to Dock
  1. Open this page in Chrome or Edge (or Firefox on Windows)
  2. Use the install icon in the address bar, or the browser menu → Install REMOVE

Firefox

  1. Windows: click the Add tab to taskbar button at the right end of the address bar, then pin the window it opens to your taskbar. No button? Update Firefox (menu ☰ → Help → About Firefox).
  2. Android: tap ⋮ → Add to Home screen (some versions say Install or Add app to Home screen).
  3. Mac or Linux: Firefox can't install it there yet. Keep using it in Firefox, or open this page in Chrome, Edge or Safari to install it.
