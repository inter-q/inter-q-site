Import or restore

Choose one or more files: .vcf (vCard), .csv, or a CONTACTS backup (.json). You can undo an import from the Menu.

iPhone

  1. Open Contacts, tap Lists
  2. Long-press All Contacts → Export → Save to Files
  3. Come back here and choose that .vcf file

Google

  1. Go to contacts.google.com → Export
  2. Pick vCard or Google CSV and save the file

Outlook

  1. People → Manage contacts → Export contacts (CSV)

Restore backup

Either way, you can undo it from the Menu.

Back up and export

Backup file (.json)

Everything, including photos and favourites. Restore it with Import. On iPhone, choose Save to Files → iCloud Drive.

With a passphrase the file is encrypted (AES-256) and useless to anyone who finds it. There is no way to recover a forgotten passphrase.

Send to iPhone Contacts

Copies your cards into the phone's own Contacts app, so Siri, CarPlay and caller ID know who's calling and who you mean.

On iPhone

  1. In the share sheet, choose Contacts. If it isn't there, choose Save to Files, then open the file in Files
  2. Tap Add All Contacts
  3. Anyone already in your iPhone gets a second copy: open Contacts, tap Duplicates Found at the top, then Merge All. Merging keeps every number from both copies, so a number you changed here stays on the phone too: delete the old one there

Install CONTACTS

CONTACTS is installed. Open it from your home screen or apps list; it works without a signal.

Install CONTACTS as an app on this device. It opens in its own window and works offline.

  1. Open this page in Safari
  2. Tap the Share button
  3. Tap Add to Home Screen, then Add
  4. Open CONTACTS from the Home Screen and import your contacts there. Cards saved in a Safari tab stay in Safari.
  1. In Safari's menu bar, choose File → Add to Dock
  1. Open this page in Chrome or Edge
  2. Use the install icon in the address bar, or the browser menu → Install CONTACTS

Install link: inter-q.com/contacts/install

Erase all cards
