Import contacts

Bring in contacts from wherever they are. You can choose several files at once: .vcf (vCard), .csv, or an IQ Contacts backup (.json).

iPhone

  1. Open Contacts, tap Lists
  2. Long-press All Contacts → Export → Save to Files
  3. Come back here and choose that .vcf file

Google

  1. Go to contacts.google.com → Export
  2. Pick vCard or Google CSV and save the file

Outlook

  1. People → Manage contacts → Export contacts (CSV)

Install IQ Contacts

IQ Contacts is installed. Open it from your home screen or apps list; it works without a signal.

Install IQ Contacts as an app on this device. It opens in its own window and works offline.

  1. Open this page in Safari
  2. Tap the Share button
  3. Tap Add to Home Screen, then Add
  1. In Safari's menu bar, choose File → Add to Dock
  1. Open this page in Chrome or Edge
  2. Use the install icon in the address bar, or the browser menu → Install IQ Contacts

Install link: inter-q.com/contacts/install
