INSTALL.EXE — LOGSTAT

Install LOGSTAT on this device. It gets its own icon and opens full-screen like any app.

Chrome / Edge / Android

If no install button appears after a few seconds, open the browser menu (⋮ or ⋯) and choose Install LOGSTAT, Install app or Add to Home screen.

LOGSTAT is already installed. You're using the app right now.
This browser can't install web apps. Open inter-q.com/logstat/install in Chrome, Edge or Safari instead.
iPhone / iPad
  1. Open this page in Safari (Chrome and Edge work too on iOS 16.4 and later).
  2. Tap the Share button, the square with an arrow pointing up (bottom of the screen in Safari; top right in Chrome). If you don't see it, tap ⋯ first.
  3. Scroll down and tap Add to Home Screen.
  4. Leave the name as LOGSTAT and tap Add.
Mac (Safari)
  1. In the menu bar choose File → Add to Dock… (or Share → Add to Dock).
  2. Click Add. LOGSTAT opens from the Dock and Launchpad like any app.

The app opens full-screen, works offline with the last version it saved, and picks up updates each time you open it online.
